# تطبيق زيد اياد للديون (Zied Aead Debts) 💰

تطبيق موبايل احترافي ومتكامل لإدارة الديون والمستحقات المالية مبني باستخدام إطار العمل **Flutter**، مخصص لمنصة **iOS** ومتوافق بالكامل مع **Android**.

يعمل التطبيق **محلياً بنسبة 100% بدون أي اتصال إنترنت أو خوادم خارجية**، مع دعم كامل للغة العربية (اتجاه RTL من اليمين لليسار)، وإدارة متزامنة لعملتي **الدينار العراقي (IQD)** و **الدولار الأمريكي (USD)**، وميزة النسخ الاحتياطي والاسترجاع الفوري.

---

## 📱 مميزات التطبيق

1. **العمل دون إنترنت (Offline-First):**
   - حفظ كافة البيانات والأشخاص والحركات على ذاكرة الجهاز باستخدام قاعدة بيانات SQLite المحلية (`sqflite`).
2. **دعم متزامن للعملتين (IQD & USD):**
   - تسجيل كل حركة بالدينار العراقي أو الدولار الأمريكي.
   - حساب صافي الرصيد لكل شخص بالعملتين بشكل مستقل في نفس الوقت.
   - حقل لسعر الصرف يدخله المستخدم يدوياً (بدون إنترنت)، لحساب الإجمالي التقديري الموحد.
3. **النسخ الاحتياطي والاسترجاع (Backup & Restore):**
   - تصدير قاعدة البيانات كملف JSON ومشاركته مباشرة عبر AirDrop أو WhatsApp أو حفظه في ملفات الجهاز أو السحابة.
   - استيراد واسترجاع البيانات في أي وقت أو عند تغيير الجهاز، مع نافذة تأكيد تحذيرية لحماية البيانات الحالية.
4. **واجهة مستخدم عصرية ولمسات 3D:**
   - ظلال ناعمة ومتعددة الطبقات (Soft 3D Shadows).
   - تدرجات لونية راقية في الأزرار والبطاقات.
   - انيميشن حركي سلس عند التنقل وظهور العناصر (`flutter_animate`).
   - خط **Cairo** العربي الجميل والأنيق.
   - دعم كامل للوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode).
5. **شاشة تقارير وإحصائيات:**
   - رسوم بيانية دائرية (Donut Charts) توضح نسبة ديون "لي" مقابل "علي" لكل عملة.
   - إحصائيات سريعة للحسابات النشطة وخالصة الذمة.

## 🚀 كيفية تشغيل واختبار المشروع (How to Run)

### المتطلبات الأساسية:
1. تثبيت **Flutter SDK** (إصدار 3.0.0 أو أحدث).
2. محرر أكواد مثل **VS Code** أو **Android Studio** مع تثبيت إضافة Flutter & Dart.
3. جهاز محاكي (iOS Simulator / Android Emulator) أو هاتف حقيقي متصل بالكمبيوتر.

### خطوات التشغيل:

1. **تحميل الاعتماديات (Dependencies):**
   افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:
   ```bash
   flutter pub get
   ```

2. **تشغيل التطبيق:**
   - **لتشغيله على محاكي iOS أو جهاز iPhone:**
     ```bash
     flutter run -d ios
     ```
   - **لتشغيله على محاكي Android أو هاتف أندرويد:**
     ```bash
     flutter run -d android
     ```
   - **لتشغيله مباشرة (سيختار الجهاز المتاح):**
     ```bash
     flutter run
     ```

3. **البيانات الأولية للتجربة:**
   - عند أول تشغيل، سيقوم التطبيق تلقائياً بإنشاء قاعدة البيانات وزرع 3 حسابات تجريبية بحركات مالية مختلفة (بالدينار والدولار) لتتمكن من معاينة الإجماليات والتصميم والرسوم البيانية فوراً.
   - يمكنك في أي وقت مسح هذه البيانات أو تصفيرها بالكامل من **شاشة الإعدادات > مسح وتصفير كافة البيانات**.
